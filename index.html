Projects

RxyCode

Featured · MIT

A local multi-agent for real work, not just code. A 100% local, vendor-neutral AI agent workbench — bring your own API key (encrypted with OS-native DPAPI), pick from 11 provider strategies (DeepSeek, Kimi, Qwen, Doubao, GLM, MiniMax, OpenAI, Anthropic and more), and run everything on your machine.

  • Agent core — headless Python runtime over a LangGraph plan → execute → validate → synthesize pipeline, ~30 built-in tools, fast path for simple turns.
  • Three surfaces, one protocol — Bun + React 19 terminal UI, Ink fallback TUI, and an Electron 39 desktop workbench, all driven by a versioned JSON-RPC protocol (141 request models) with CI-enforced TypeScript codegen.
  • Multi-agent system — a 10-role Expert Team over 7 deterministic SOP stages, a mechanical 8-check verification gate, budget fuses, and isolated subagents with workspace leases.
  • Memory & RAG, zero heavy deps — tiered memory, AST-aware chunking, NumPy cosine index, PageRank repo map; no external vector database.
  • Safety & reliability — three-tier approval gate, crash-safe at-most-once side-effect journal, durable checkpoints with rewind and replayable traces.
  • Scale — ~150K lines of Python, ~400K lines of TS/TSX, 12,876 backend tests, ConPTY end-to-end CI, coverage gates and secret scanning.
